# J&J OS — V5 Customers Foundation

Production-oriented Next.js + Supabase foundation with:
- Supabase SSR cookie sessions
- Supabase publishable key support
- Login / signup
- Company onboarding
- RLS company isolation
- Live Customers CRUD (create + list)

## Environment
`NEXT_PUBLIC_SUPABASE_URL`
`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

## Local
`npm install`
`npm run dev`

Before first use, run `supabase/schema.sql` in the Supabase SQL Editor.
